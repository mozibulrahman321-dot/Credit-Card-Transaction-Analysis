# Credit Card Transaction Analysis

An interactive Power BI dashboard for analyzing credit card transaction performance, revenue, interest earned, customer demographics, card categories, transaction methods, and spending patterns.

The project focuses on transforming transaction data into a structured and interactive business intelligence report that can be used to understand overall performance and explore customer-level trends.

## Dashboard Overview

The dashboard provides a consolidated view of key credit card performance metrics along with interactive analysis across different customer and transaction dimensions.

### Key Performance Indicators

| Metric | Value |
| Total Revenue | 55.3M |
| Total Interest Earned | 7.8M |
| Total Transaction Amount | 44.5M |
| Total Transaction Count | 656K |

## Analysis

The dashboard covers the following areas:

### Quarterly Performance

Analysis of revenue and transaction count across quarters to understand changes in transaction activity and overall performance over time.

### Revenue by Card Category

Revenue is analyzed across different card categories:

- Blue
- Silver
- Gold
- Platinum

### Revenue by Transaction Method

The dashboard compares revenue generated through different transaction methods:

- Swipe
- Chip
- Online

### Revenue by Expense Type

Customer spending is analyzed across major expense categories, including:

- Bills
- Entertainment
- Fuel
- Grocery
- Food
- Travel

### Revenue by Education

Revenue is segmented by customer education level to understand the distribution of transaction activity across different customer groups.

### Revenue by Age Group

Customer revenue is analyzed across different age groups to identify differences in transaction contribution across demographic segments.

### Gender Analysis

The dashboard supports gender-based analysis through interactive filtering, allowing users to compare transaction performance across customer segments.

## Interactive Filters

The report includes slicers that allow users to dynamically filter and analyze the dashboard.

Available filters include:

- Quarter
- Card Category
- Week Start Date
- Gender

Changes to these filters dynamically update the report visuals and KPIs.
